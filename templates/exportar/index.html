Informes · Exportar a Excel

Todo resultado de PlanEstrat puede exportarse a Excel con formato. Este módulo genera el archivo con openpyxl a partir de un modelo de hojas; los demás módulos usan este mismo motor para descargar sus tablas.

Cómo funciona

El modelo describe una o más hojas: { "titulo": "...", "hojas": [ { "nombre": "...", "encabezados": [...], "filas": [[...]] } ] }.

El servidor construye el libro .xlsx con encabezados con formato y ancho de columnas automático, y lo entrega como descarga. Cada módulo arma este modelo con sus resultados y lo envía a este mismo endpoint.

Edita el JSON (hojas, encabezados y filas). El ejemplo trae los objetivos y KPIs del caso Los Ríos.
